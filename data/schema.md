# Emotion → activity dataset: schema and usage

Generated by `scripts/build_dataset.py` (with `scripts/combination_build.py` and this template, `scripts/schema_template.py`) from the research notes in `research_notes/Emotion to activity evidence map/` and `research_notes/Emotion combination evidence map/`, the per-citation verification CSVs in `data/verification/`, and the hand-curated tables in `data/curation/`. Do not edit the output files by hand: change a curation file (or the notes) and re-run the script.

**Read this first.**

- This is a general-wellbeing suggestion dataset, not a clinical tool. Effects are small on average; say an activity *may help*.
- No statistic, DOI or PMID was generated for this dataset. Every such value is copied from a notes table or a verification CSV. Where the notes say *unverified / not confirmed / not in PubMed*, that wording is kept in the text cell and the link is flagged.
- All numeric thresholds (0.4, 0.75, 0.9) and all scoring weights are **uncalibrated engineering defaults**.
- **Many combination rules are still extrapolations** from single-emotion evidence (see `evidence_basis`). Combination evidence now exists for some pairs (`combination_evidence.csv`): 22 of 66 matrix rows have at least one suggestion backed by same-sample or direct combination evidence, most of it from multi-week programmes rather than 5-30 minute sessions.
- Verification tags from the combination notes are carried through verbatim: `[PM-full]` (read in PMC full text), `[PM-abs]` (PubMed abstract), `[prior-notes]` (taken from the first notes), `[web]` (web summary only), `[memory]` (not verified). Rows tagged `[web]` or `[memory]` should not be quoted as established numbers.
- The notes conclude that an emotion reading from a drawing or handwriting sample is not validated. The user's own one-tap self-report should drive the lookup; the LLM reading is a tentative guess (see `safety.json`).

## recommendations.json — how `evidence_score` is computed

For each emotion, every *benefit* link to a suggestable activity gets a `link_score`, the product of six factors:

```
link_score = level × strength × verification × session × mapping × modifiers
```

| factor | values |
|---|---|
| level (`evidence_level_class`) | meta_analysis 1.0, systematic_review 0.8, rct 0.8, experiment 0.6, observational 0.35, indirect 0.15 |
| strength (`evidence_strength_class`) | strong 1.0, moderate 0.7, preliminary 0.4 |
| verification (`verification_status`) | verified_fulltext 1.0, verified_abstract 0.95, corrected 0.95, citation_exists_number_not_confirmed 0.7, not_in_pubmed 0.5, not_found 0.25, unverified 0.25 |
| session (`single_session_evidence`) | true 1.0, unknown 0.8, false 0.5 — the app suggests things to do now, so programme-only evidence is discounted |
| mapping | direct 1.0, proxy 0.6, aggregate 0.4 — *aggregate* = a `negative_affect_general` link counted toward stressed/anxious/angry/sad |
| modifiers | × 0.6 if the notes mark 'low applicability'; × 0.85 if the citation is verified but the row still contains unconfirmed wording; × 0.8 if the evidence is category-level |

Then, per (emotion, activity):

```
evidence_score = min(1, best_link_score + 0.1 × Σ link_score of links from OTHER distinct papers)
evidence_score ×= 0.5            if the activity is plan_to
```

Excluded from the ranking: activities with `suggest_mode` avoid / reference_only; activities `contraindicated_for` that emotion; activities with a harm link for that emotion. Those appear under `avoid` with the reason and citation. Activities whose only evidence for the emotion is a null result appear under `no_benefit_found`.

The score orders options by how well supported and how verifiable they are. It is **not** an effect size and not a probability of helping. The weights were chosen for this build and have not been calibrated against outcomes.

| field | type | meaning |
|---|---|---|
| `by_emotion.<id>.recommended[]` | object[] | ranked: `rank`, `activity_id`, `evidence_score`, `n_supporting_links`, `n_distinct_citations`, `best_link_id`, `best_link_mapping`, `top_citation`, `top_citation_doi_or_url`, `top_citation_pmid`, `top_citation_verification_status`, `single_session_evidence`, `suggest_mode`, `effort`, `arousal_effect`, `in_single_emotion_rule`, `flags`, `why` |
| `avoid[]` | object[] | activities not to suggest for this emotion, with reasons |
| `no_benefit_found[]` | object[] | activities with only null evidence for this emotion |
| `rule_fallback` | object | activities allowed by the emotion's own matching rule that have no benefit row for it (extrapolated) |
| `evidence_depth` | object | counts, plus `thin_evidence` (< 5 suggestable activities with a direct, verified benefit link) and `thin_for_right_now_use` (< 5 right-now activities whose direct, verified benefit link includes single-session evidence) |
| `single_emotion_rule` | string or null | R03–R09 where one exists |

- **Restless** has no evidence row and no rule of its own in the notes; everything offered for it is a fallback marked extrapolated.
- **Bored**: the only direct, verified benefit is the challenge-matched game experiment; the rest is theory (MAC model) or proxy outcomes.
- **Lonely**: programme-level meta-analyses plus a handful of single-session experiments whose outcomes are felt connection or mood, not chronic loneliness.
- **Overwhelm** is mapped to `stressed`. Its rows measure sleep onset, intrusive task thoughts or goal attainment, not felt overwhelm, so they are mapped as *proxy*.
- **Angry**: one strong meta-analysis (category-level: arousal-decreasing activities) carries almost all of the evidence.
- **Sad**: much of the strong evidence is programme-level and in clinical samples; single-session mood-repair studies (drawing) are mostly not indexed in PubMed.
- **Calm / energetic / neutral**: few rows; treat suggestions as ways to sustain or channel the state.

**Rule evidence_basis upgrade.** A rule is upgraded (never downgraded) to `direct_combination_evidence` if any activity in its recommend or follow-up list has a `both_improved` row for the rule's combination with `evidence_basis = directly_tested_on_combination` and a combo_score ≥ 0.25; to `same_sample_evidence` if such a row is `same_sample_both_outcomes`. The rule's combination is its pair, its triple, or (for R31) every 3-subset of the cluster. Plan-ahead activities count here (e.g. empathy_phone_call for R12/R16), so an upgraded rule can still have no right-now suggestion with combination evidence; the matrix basis below only counts right-now picks.

**combo_score.** For a combination and an activity, every `both_improved` row whose basis is direct, same-sample or pooled gets

```
combo_weight = tag × design × basis × mapping
combo_score  = min(1, best combo_weight + 0.1 × Σ best combo_weight of each OTHER distinct study)
```

| factor | values |
|---|---|
| tag (`verification_tag_conservative`) | [PM-full] 1.0, [PM-abs] 0.9, [prior-notes] 0.8, [web] 0.5, [memory] 0.3 |
| design (`design_class`) | meta_analysis 1.0, rct 0.85, controlled_or_crossover 0.65, quasi_experimental 0.55, pre_post 0.45, systematic_review 0.4, observational 0.3, other 0.3 |
| basis (`evidence_basis`) | directly_tested_on_combination 1.0, same_sample_both_outcomes 0.8, pooled_parallel_outcomes 0.5, single_emotion_extrapolation 0.0 |
| mapping (`activity_mapping`) | exact 1.0, close 0.85, proxy 0.6 |

A triple's combo_score uses study rows in which the same activity had `both_improved` rows for all three pairs (weight = the lowest of the three), plus mixed-state rows whose combination is the triple. All weights are uncalibrated design defaults.

**prevalence_tier thresholds (judgement calls).** A row is `common` if a correlation is ≥ 0.4 (within-person r ≥ 0.4), a conditional or profile percentage is ≥ 70%, or an ESM study names the pair among the most frequent opposite-valence co-occurrences; `moderate` if r ≥ 0.25 (within-person ≥ 0.25), a percentage is ≥ 30%, or the two load on the same factor; otherwise `rare_or_unknown` (including negative correlations, experimental-only links and no data). ## combination_matrix.csv

66 rows: all 66 pairs of the 12 classes. Derivation: {'pair_rule': 18, 'composed_from_single_emotion_rules': 14, 'group_rule_mixed_valence': 23, 'single_emotion_rule': 7, 'no_rule_in_notes_default': 4}. Evidence basis before combination evidence (rule only): {'extrapolated': 58, 'partly': 6, 'directly_tested': 2}; after: {'direct_combination_evidence': 4, 'partly': 5, 'extrapolated': 37, 'same_sample_evidence': 18, 'directly_tested': 2}. Prevalence tiers: {'common': 19, 'rare_or_unknown': 44, 'moderate': 3}. 22 rows have at least one pick backed by combination evidence.

How a row is derived:

1. **Pick the governing rule.** A pair rule (R10–R26, R37) if one exists; else R27 if one emotion is positive and the other negative; else *compose* the two single-emotion rules (tension emotion first, classes interleaved, union of both avoid lists, effort limits and avoided classes). `restless` has no single rule, so a curated fallback is used. Any mixed-valence plan also appends R38's classes (savour, share, easy movement). **Pairs with `neutral`** are routed to the other emotion's single lookup (neutral adds no rule, no evidence and no avoid list); their `derivation` starts with `neutral_routed:`.
2. **Candidates** = right-now activities in the allowed classes (plus the rule's extra ids) **or with combination evidence for the pair**, minus the avoid list, minus anything contraindicated for either emotion, minus every activity with a `one_worsened` row for the pair (`contraindicated_by_combo_evidence`).
3. **Tiers.** Tier 0 = combo_score ≥ 0.25 (combination evidence, ranked by combo_score); tier 1 = rule-allowed; tier 2 = evidence for either emotion only.
4. **Score** (used inside a tier) = 0.3 × in_rule + mean of the two per-emotion `evidence_score`s (0 where there is none) + 0.1 × class-order bonus + 0.5 × combo_score.
5. **Select 3–5**: slot 1 is the rule's explicit first activity if it has one (R27 excited + anxious → `arousal_reappraisal`; R12 and R34 → `send_message`, 'text before call'), else the best tier-0 candidate, else the best candidate of the rule's first-listed class. Then, at each diversity level (one per class, then two, then any), tier-0 candidates are taken before tier-1 ones; tier-2 candidates come last.
6. **evidence_basis** = the rule-only basis, upgraded to `direct_combination_evidence` / `same_sample_evidence` if a selected tier-0 pick has a direct / same-sample (not just pooled) both-improved row for the pair.

## Decision procedure for the app

Input: `scores` = `{emotion_id: 0..1}` (after the user has confirmed or corrected the label), `likes` and `dislikes` = preference tags, categories or activity ids. `Recommender.recommend()` in `scripts/build_dataset.py` is a reference implementation of exactly this.

```text
0. Map any free-text label to a class with emotions.json → synonym_index. Unknown label → ask the user.
   If the user corrected the label, use the user's label and ignore the model's.
1. SAFETY GATE (R30): if any negative score ≥ 0.9, or the app's persistence / self-harm-cue / severe-self-report
   signal is set → show safety.json → crisis_gate, no activity list. Stop.
   Apply the persistence check with extra care when the profile is lonely + sad + anxious (R34) or bored + sad persists (R35).
2. active = classes with score ≥ 0.4 (not neutral), highest first; keep the top 2
   (keep a 3rd only if it is within 0.1 of the 2nd). None active → neutral: R25 with the calm+content evidence scores.
3. derived: tension = max(stressed, anxious, angry, restless); energy = energetic − max(tired, 0.5·bored);
   intensity = max negative score.
4. Pick the governing rule:
     three kept  → combination_rules.meta.triple_index[a+b+c]        (triple rule R32–R36)
                 → else R31 if ≥ 3 of stressed/anxious/angry/sad    (tense-distress cluster)
                 → else drop the 3rd to 'contraindications only' and continue with the top two
     two active  → combination_rules.meta.pair_index[a+b]            (pair rule, incl. R37 anxious+restless)
                 → else R27 if one is positive and one negative     (mixed valence)
                 → else compose the two single-emotion rules        (tension emotion first; union of avoid lists)
                 any mixed-valence plan appends R38 (savour / share / easy movement; keep the positive part)
     one active  → its single-emotion rule (R03–R09); positive → R24/R25; restless → meta.restless_fallback
5. candidates = right-now activities that are in the rule's allowed set OR have combination evidence for the
   governing combination (combination_matrix / combination_triples: same_sample_activity_ids, pooled_...),
   minus avoid_activity_ids, minus contraindicated_for any active emotion, minus contraindicated_by_combo_evidence,
   minus the user's dislikes (hard filter), minus activities whose requirements the user cannot meet (app-side).
6. tier 0 = combo_score ≥ 0.25 (ranked by combo_score); tier 1 = rule-allowed; tier 2 = single-emotion evidence only.
   score = 0.3·in_rule + mean over the governing emotions of recommendations[e].evidence_score
           + 0.1·class_order_bonus + 0.5·combo_score + 0.25·(liked tags matched / liked tags given)
   (add your own + w_hist·past_helpfulness − w_repeat·recently_shown once you have feedback data)
7. INTENSITY GATE (R01): if intensity ≥ 0.75, slot 1 must come from BREATHE / SENSORY / DISTRACT / MOVE-LOW,
   and activities contraindicated for context high_intensity (reappraisal, perspective-taking, expressive writing) are dropped.
   Otherwise slot 1 = the rule's explicit first activity (R27 excited + anxious → arousal_reappraisal; R12/R34 → send_message),
   else the best tier-0 candidate, else the best candidate from the rule's first-listed class.
8. Fill up to 3 suggestions: one per rule class before repeating a class, tier 0 before tier 1 at each level,
   tier 2 last. Show them as options and let the user choose (R29). plan_to activities (e.g. empathy_phone_call) may be shown as 'for later'.
9. If the rule has ask_user (controllability question), offer PLAN on 'yes' and REAPPRAISE on 'no' as the follow-up.
   If the user picks music while in a negative state, apply R28 (match the mood first, then shift over 2–3 tracks).
10. Honest copy: 'may help a bit right now'; for loneliness 'one message is a start'; for fatigue 'a short walk tends to lift energy; rest helps too'.
11. Afterwards ask 'Did that help?' and store the answer for ranking.
```

Preferences only reorder options **inside** the allowed set; they never bring back something on an avoid list or with `one_worsened` evidence.

## Judgement calls made in this build

- **Activity merging.** Raw activity labels were merged only where they describe the same thing to do (e.g. all structured-colouring rows; the three 10-minute brisk-walk rows). Free dancing vs dance programmes, drawing-to-distract vs drawing-something-happy vs drawing-to-vent, running vs generic moderate exercise, and short nap vs caffeine nap are kept apart. The mapping is in `curation/activity_map.csv`.
- **'Any physical activity' and 'aerobic exercise'** rows are mapped to one activity, `moderate_exercise`.
- **Category-level evidence.** The Kjærvik & Bushman 'arousal-decreasing activities' row is attached to slow breathing, mindfulness meditation and progressive muscle relaxation with `category_level_evidence = true` (the abstract names deep breathing, mindfulness and meditation; PMR is named in the notes row only).
- **Emotion mapping.** Depression / low-mood outcomes map to `sad`; fatigue, low energy and sleepiness to `tired`; overwhelm to `stressed`; worry to `anxious`. Positive-affect outcomes map to `content` and, as a proxy, to `sad` (low positive affect is the depression-specific component in the tripartite model cited in the notes). Cortisol / HRV-only outcomes map to `stressed` as a proxy. Rumination maps to `sad` and `anxious` as a proxy.
- **Aggregate targets.** Rows about negative emotion in general are held under `negative_affect_general` and count toward stressed, anxious, angry and sad only, at a reduced weight. General wellbeing and sleep rows are kept but not used in rankings.
- **`suggest_mode`.** Activities whose evidence is programme-level, needs a group, or is not a 5–45 minute action are `plan_to`; therapist-led or generic rows are `reference_only`; documented backfires are `avoid`. Supplements (L-theanine) are `reference_only`; cold-water immersion is `avoid` (no immediate effect in the RCT meta-analysis, cardiac caution).
- **Contraindications beyond the notes' explicit rows.** Because arousal-increasing activities did not reduce anger, `free_dancing`, `stair_walking`, `upbeat_music_listening`, `moderate_exercise`, `running_jogging`, `hiit` are marked contraindicated for `angry`. This generalises the category-level finding; the notes only name running/jogging, hitting a bag and cycling.
- **Instructions, `typical_duration_min`, `arousal_effect`, `effort`, `requirements`** are curated summaries, not quotations. `min_effective_dose` quotes the notes and keeps their caveats.
- **Direction, single-session and numeric-effect fields** are produced by documented heuristics with a short override list (`curation/link_overrides.csv`). Where a cell holds several values, `effect_size_value` is left empty.
- **Verification status per link** is the status of the row's first citation in the same notes file's verification CSV; all citations' statuses are listed alongside. `corrected` is scored like `verified_abstract` because the value was fixed against PubMed.
- **Restless** has no rule or evidence in the notes; a fallback class list was written for it and is marked extrapolated.
- **R15 'very small step'** is encoded as `max_typical_duration_min = 20`. **Calm music** in R10/R21/R26 is encoded by listing `upbeat_music_listening` as avoided. **'Easy creative task'** (R20) and **'gentle creative hobby'** (R25) are encoded as explicit activity ids.
- **Single-emotion rule thresholds.** R04 is written for 'moderate' stress; it is also used as the lookup for stressed ≥ 0.75, where R01 then gates the first suggestion.
- **Scoring weights and the selection logic** (rule bonus, class-order bonus, preference weight, one-per-class diversity) are design defaults of this build. The notes give only the general ranking formula and the principle that preferences rank inside the rule-allowed set.
- **Synonym lists** for LLM labels are a design aid and not derived from the notes, apart from the raw target strings listed under `notes_target_labels`.
- **Combination notes: class mapping.** The notes' own mappings are kept: POMS tension-anxiety and STAI → `anxious` (not `stressed`), PSS/DASS stress and cortisol → `stressed`, depression-dejection → `sad`, fatigue → `tired`, vigor and PANAS-PA → `energetic`, positive mood/happiness → `content`, UCLA loneliness → `lonely`, interest (inverse) → `bored`. PANAS-NA, TMD and other composites are not a class, so rows whose only pairs involve them produce no combination row.
- **Messy pair cells.** 'all with energetic↑', '+energetic', 'any+energetic', 'any pair with tired', 'etc.' are expanded to explicit pairs in `combo_pair_overrides.csv`; each expansion is documented there. Unsupported pairs are classified from the per-emotion cells (worsened → one_worsened; both ns → neither_improved; else one_not_improved).
- **Direct vs same-sample.** Rows are marked `directly_tested_on_combination` only where the notes describe a mixed-state sample or induced blend: high stress + depressive symptoms (breathing, 39606690), mixed DASS distress (PMR + imagery, 29619392), depressed women with fatigue (forest, 40277811), stressed and fatigued ICU nurses (PMR + music), homebound adults on loneliness/depression/anxiety (Kahlon 2021), plus the mixed-state table's own `directly_tested_on_combination` rows. Meta-analyses and reviews that pool each outcome separately are `pooled_parallel_outcomes`, weighted at half of same-sample.
- **Not-superior-to-control results.** Where both emotions improved but no more than quiet rest or an active control (Bartholomew 2005; choir vs health education; laughter therapy vs TV), the row is `mixed` or `neither_improved`, not `both_improved`.
- **Single-emotion rows in the mixed-state table** are attached to the pair(s) of the rule they cite (e.g. Loy 2013 → stressed+tired and sad+tired via R10/R15) with outcome `single_emotion_only`; they never enter the combination tier.
- **Outcome classes beyond the four requested** (`neither_improved`, `single_emotion_only`, `proxy_outcome`, `association_only`, `general_principle`) were added so that correlational, proxy-outcome and principle rows are not forced into an improvement class.
- **New activities.** `arousal_reappraisal` ('I am excited' self-talk), `distanced_journaling` (the written form of self-distanced reflection; tested as reflection, so mapped as proxy), `empathy_phone_call` (plan_to: the Kahlon programme) and `acquire_pet` (avoid, kept to trace the pet-ownership null). The first two have no rule classes, so they appear only where a rule names them (R11, R27; R13, R17, R33).
- **Rule revisions** follow the notes' rule review; where the report adds detail that the notes support (R15 rest first-line, R22 breathing and mindfulness first, R14 distraction), it is encoded and stated in `revision_note`. R31–R38 use the IDs proposed in the report; R38 (positive + negative blend) is a modifier appended to every mixed-valence plan rather than a competing rule.
- **Tier 0 ordering.** Activities with combination evidence (combo_score ≥ the threshold) are ranked before rule-allowed ones and may come from classes the rule does not list (never from avoided classes or ids). A rule's explicit first activity (R27 excited + anxious) and the R01 intensity gate still take slot 1.
- **Prevalence tiers** are judgement calls: clinical symptom percentages count as co-occurrence, social anxiety is capped as a proxy for anxious, and a pair takes the best of its rows. Neutral has no data in any source.
- **Triples** are generated from the prevalence data (every pair common, or a common triple row) plus triple rules; a triple with no triple rule is governed by one pair rule plus the third emotion's contraindications, which is a simplification.
