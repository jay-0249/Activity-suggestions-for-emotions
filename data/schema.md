# Emotion → activity dataset: schema and usage

Generated by `scripts/build_dataset.py` from the research notes in `research_notes/Emotion to activity evidence map/`, the per-citation verification CSVs in `data/verification/`, and the hand-curated tables in `data/curation/`. Do not edit the output files by hand: change a curation file (or the notes) and re-run the script.

**Read this first.**

- This is a general-wellbeing suggestion dataset, not a clinical tool. Effects are small on average; say an activity *may help*.
- No statistic, DOI or PMID was generated for this dataset. Every such value is copied from a notes table or a verification CSV. Where the notes say *unverified / not confirmed / not in PubMed*, that wording is kept in the text cell and the link is flagged.
- All numeric thresholds (0.4, 0.75, 0.9) and all scoring weights are **uncalibrated engineering defaults**.
- **Most combination rules are extrapolations** from single-emotion evidence (see `evidence_basis`).
- The notes conclude that an emotion reading from a drawing or handwriting sample is not validated. The user's own one-tap self-report should drive the lookup; the LLM reading is a tentative guess (see `safety.json`).

## recommendations.json — how `evidence_score` is computed

For each emotion, every *benefit* link to a suggestable activity gets a `link_score`, the product of six factors:

```
link_score = level × strength × verification × session × mapping × modifiers
```

| factor | values |
|---|---|
| level (`evidence_level_class`) | meta_analysis 1.0, systematic_review 0.8, rct 0.8, experiment 0.6, observational 0.35, indirect 0.15 |
| strength (`evidence_strength_class`) | strong 1.0, moderate 0.7, preliminary 0.4 |
| verification (`verification_status`) | verified_fulltext 1.0, verified_abstract 0.95, corrected 0.95, citation_exists_number_not_confirmed 0.7, not_in_pubmed 0.5, not_found 0.25, unverified 0.25 |
| session (`single_session_evidence`) | true 1.0, unknown 0.8, false 0.5 — the app suggests things to do now, so programme-only evidence is discounted |
| mapping | direct 1.0, proxy 0.6, aggregate 0.4 — *aggregate* = a `negative_affect_general` link counted toward stressed/anxious/angry/sad |
| modifiers | × 0.6 if the notes mark 'low applicability'; × 0.85 if the citation is verified but the row still contains unconfirmed wording; × 0.8 if the evidence is category-level |

Then, per (emotion, activity):

```
evidence_score = min(1, best_link_score + 0.1 × Σ link_score of links from OTHER distinct papers)
evidence_score ×= 0.5            if the activity is plan_to
```

Excluded from the ranking: activities with `suggest_mode` avoid / reference_only; activities `contraindicated_for` that emotion; activities with a harm link for that emotion. Those appear under `avoid` with the reason and citation. Activities whose only evidence for the emotion is a null result appear under `no_benefit_found`.

The score orders options by how well supported and how verifiable they are. It is **not** an effect size and not a probability of helping. The weights were chosen for this build and have not been calibrated against outcomes.

| field | type | meaning |
|---|---|---|
| `by_emotion.<id>.recommended[]` | object[] | ranked: `rank`, `activity_id`, `evidence_score`, `n_supporting_links`, `n_distinct_citations`, `best_link_id`, `best_link_mapping`, `top_citation`, `top_citation_doi_or_url`, `top_citation_pmid`, `top_citation_verification_status`, `single_session_evidence`, `suggest_mode`, `effort`, `arousal_effect`, `in_single_emotion_rule`, `flags`, `why` |

- **Angry**: one strong meta-analysis (category-level: arousal-decreasing activities) carries almost all of the evidence.
- **Sad**: much of the strong evidence is programme-level and in clinical samples; single-session mood-repair studies (drawing) are mostly not indexed in PubMed.
- **Calm / energetic / neutral**: few rows; treat suggestions as ways to sustain or channel the state.

## combination_matrix.csv

34 rows: all 28 pairs of the 8 negative-state emotions plus the key mixed/positive pairs. Derivation: {'pair_rule': 17, 'composed_from_single_emotion_rules': 14, 'group_rule_mixed_valence': 3}. Evidence basis: {'extrapolated': 31, 'partly': 3}.

How a row is derived:

1. **Pick the governing rule.** A pair rule (R10–R26) if one exists; else R27 if one emotion is positive and the other negative; else *compose* the two single-emotion rules (tension emotion first, classes interleaved, union of both avoid lists, effort limits and avoided classes). `restless` has no rule, so a curated fallback is used.
2. **Candidates** = right-now activities in the allowed classes (plus the rule's extra ids), minus the avoid list, minus anything contraindicated for either emotion.
3. **Score** = 0.3 (in rule) + mean of the two per-emotion `evidence_score`s (0 where there is no evidence) + 0.1 × class-order bonus.
4. **Select**: slot 1 is the best candidate from the rule's first-listed class (the rules encode 'do this first'); remaining slots by score, one per class before any class repeats; rule-allowed candidates are exhausted before evidence-only ones.

## Decision procedure for the app

Input: `scores` = `{emotion_id: 0..1}` (after the user has confirmed or corrected the label), `likes` and `dislikes` = preference tags, categories or activity ids. `Recommender.recommend()` in `scripts/build_dataset.py` is a reference implementation of exactly this.

```text
0. Map any free-text label to a class with emotions.json → synonym_index. Unknown label → ask the user.
   If the user corrected the label, use the user's label and ignore the model's.
1. SAFETY GATE (R30): if any negative score ≥ 0.9, or the app's persistence / self-harm-cue / severe-self-report
   signal is set → show safety.json → crisis_gate, no activity list. Stop.
2. active = classes with score ≥ 0.4 (not neutral), highest first; keep the top 2
   (keep a 3rd only if it is within 0.1 of the 2nd; it only adds its contraindications).
   None active → treat as neutral: use R25 (savour / gentle options) with the calm+content evidence scores.
3. derived: tension = max(stressed, anxious, angry, restless); energy = energetic − max(tired, 0.5·bored);
   intensity = max negative score.
4. Pick the governing rule:
     two active  → combination_rules.meta.pair_index[a+b]            (pair rule)
                 → else R27 if one is positive and one negative     (mixed valence)
                 → else compose the two single-emotion rules        (tension emotion first; union of avoid lists)
     one active  → its single-emotion rule (R03–R09); positive → R24/R25; restless → meta.restless_fallback
5. candidates = activities with suggest_mode right_now that are in the rule's recommend_activity_ids,
   minus avoid_activity_ids, minus contraindicated_for any active emotion, minus the user's dislikes (hard filter),
   minus activities whose requirements the user cannot meet (app-side: outdoors, another person, materials…).
6. score(candidate) = 0.3·in_rule + mean over the top-2 emotions of recommendations[e].evidence_score(candidate)
                      + 0.1·class_order_bonus + 0.25·(liked tags matched / liked tags given)
   (add your own + w_hist·past_helpfulness − w_repeat·recently_shown once you have feedback data)
7. INTENSITY GATE (R01): if intensity ≥ 0.75, slot 1 must come from BREATHE / SENSORY / DISTRACT / MOVE-LOW,
   and activities contraindicated for context high_intensity (reappraisal, perspective-taking, expressive writing) are dropped.
   Otherwise slot 1 = best candidate from the rule's first-listed class.
8. Fill up to 3 suggestions by score, one per rule class before repeating a class.
   Show them as options and let the user choose (R29). plan_to activities may be shown separately as 'for later'.
9. If the rule has ask_user (controllability question), offer PLAN on 'yes' and REAPPRAISE on 'no' as the follow-up.
   If the user picks music while in a negative state, apply R28 (match the mood first, then shift over 2–3 tracks).
10. Afterwards ask 'Did that help?' and store the answer for ranking.
```

Preferences only reorder options **inside** the rule-allowed set; they never bring back something on an avoid list.

## Worked example

Input: `{"stressed": 0.7, "tired": 0.5}`, likes `["creative", "indoor", "solo"]`.

1. Safety gate: highest negative score is 0.7 < 0.9 → continue.
2. Active emotions (≥ 0.4): stressed, tired.
3. Derived: tension = 0.7, energy = -0.5, intensity = 0.7 (< 0.75, so the R01 intensity gate is off).
4. Rule: `R10`, `R29` — derivation `pair_rule`, evidence basis **extrapolated**. Allowed classes in order: BREATHE, MOVE-LOW, SENSORY, MUSIC, REST. Effort excluded: high. Explicitly avoided: caffeine_nap, upbeat_music_listening.
5. 47 candidates remain after the avoid list, effort limit and contraindications.
6–8. Scores and selection:

| slot | activity | class | mean evidence | preference match | score | instruction / name |
|---|---|---|---|---|---|---|
| suggestion 1 | `slow_breathing` | BREATHE | 0.364 | 0.667 | 0.931 | Breathe slowly and gently, at roughly six breaths a minute, for five minutes or more. Do not hold your breath for long or breathe fast. |
| suggestion 2 | `nap_short` | REST | 0.576 | 0.667 | 1.063 | Set an alarm and nap for about ten minutes, ideally early afternoon. Longer naps can leave you groggy. |

## Judgement calls made in this build

- **Activity merging.** Raw activity labels were merged only where they describe the same thing to do (e.g. all structured-colouring rows; the three 10-minute brisk-walk rows). Free dancing vs dance programmes, drawing-to-distract vs drawing-something-happy vs drawing-to-vent, running vs generic moderate exercise, and short nap vs caffeine nap are kept apart. The mapping is in `curation/activity_map.csv`.
- **'Any physical activity' and 'aerobic exercise'** rows are mapped to one activity, `moderate_exercise`.
- **Category-level evidence.** The Kjærvik & Bushman 'arousal-decreasing activities' row is attached to slow breathing, mindfulness meditation and progressive muscle relaxation with `category_level_evidence = true` (the abstract names deep breathing, mindfulness and meditation; PMR is named in the notes row only).
- **Emotion mapping.** Depression / low-mood outcomes map to `sad`; fatigue, low energy and sleepiness to `tired`; overwhelm to `stressed`; worry to `anxious`. Positive-affect outcomes map to `content` and, as a proxy, to `sad` (low positive affect is the depression-specific component in the tripartite model cited in the notes). Cortisol / HRV-only outcomes map to `stressed` as a proxy. Rumination maps to `sad` and `anxious` as a proxy.
- **Aggregate targets.** Rows about negative emotion in general are held under `negative_affect_general` and count toward stressed, anxious, angry and sad only, at a reduced weight. General wellbeing and sleep rows are kept but not used in rankings.
- **`suggest_mode`.** Activities whose evidence is programme-level, needs a group, or is not a 5–45 minute action are `plan_to`; therapist-led or generic rows are `reference_only`; documented backfires are `avoid`. Supplements (L-theanine) are `reference_only`; cold-water immersion is `avoid` (no immediate effect in the RCT meta-analysis, cardiac caution).
- **Contraindications beyond the notes' explicit rows.** Because arousal-increasing activities did not reduce anger, `free_dancing`, `stair_walking`, `upbeat_music_listening`, `moderate_exercise`, `running_jogging`, `hiit` are marked contraindicated for `angry`. This generalises the category-level finding; the notes only name running/jogging, hitting a bag and cycling.
- **Instructions, `typical_duration_min`, `arousal_effect`, `effort`, `requirements`** are curated summaries, not quotations. `min_effective_dose` quotes the notes and keeps their caveats.
- **Direction, single-session and numeric-effect fields** are produced by documented heuristics with a short override list (`curation/link_overrides.csv`). Where a cell holds several values, `effect_size_value` is left empty.
- **Verification status per link** is the status of the row's first citation in the same notes file's verification CSV; all citations' statuses are listed alongside. `corrected` is scored like `verified_abstract` because the value was fixed against PubMed.
- **Restless** has no rule or evidence in the notes; a fallback class list was written for it and is marked extrapolated.
- **R15 'very small step'** is encoded as `max_typical_duration_min = 20`. **Calm music** in R10/R21/R26 is encoded by listing `upbeat_music_listening` as avoided. **'Easy creative task'** (R20) and **'gentle creative hobby'** (R25) are encoded as explicit activity ids.
- **Single-emotion rule thresholds.** R04 is written for 'moderate' stress; it is also used as the lookup for stressed ≥ 0.75, where R01 then gates the first suggestion.
- **Scoring weights and the selection logic** (rule bonus, class-order bonus, preference weight, one-per-class diversity) are design defaults of this build. The notes give only the general ranking formula and the principle that preferences rank inside the rule-allowed set.
- **Synonym lists** for LLM labels are a design aid and not derived from the notes, apart from the raw target strings listed under `notes_target_labels`.
