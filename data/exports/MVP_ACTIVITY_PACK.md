# MVP activity pack: hand-off for the app repo

**For a coding agent adding activities to the MVP's fixed lookup table.** Read this file, then `mvp_activity_pack.json`.

## What this is

`mvp_activity_pack.json` holds 43 class-activity rows (31 unique activities) for the five sketch classes the MVP already uses: `stress`, `anxiety`, `mental_fatigue`, `calm_flow` and `radiant_joy`. Each class lists 8–10 activities in recommended order. Each activity carries app-ready text (title, subtitle, steps, duration, interaction type) and one to three peer-reviewed citations with DOI, PMID and how far each was checked.

`mvp_activity_pack.csv` is the same content flattened to one row per class-activity, with only the top citation. Use it for review, not as the source of truth.

The pack is generated by `scripts/build_mvp_activity_pack.py` in the research repo, from `data/curation/mvp_activity_pack.json` (wording) and `data/evidence_links.json` (citations). Don't hand-edit citations; they come straight from the research dataset.

## How it maps onto the current MVP

| MVP today | In the pack |
|---|---|
| `ACTIVITIES[class]` in gate.py, 3 per class | `classes[class].activities`; the first 3 have `default_three: true` |
| id | `id` (snake_case; the same activity can appear in several classes, e.g. `slow_breathing`) |
| title, subtitle | `title`, `subtitle` |
| duration (60–90 s) | `short_version_seconds` (≤ 90 s, where a short version makes sense) and `duration_seconds` (recommended length) |
| interaction type (pendulum pacer, 4-7-8 breath orb) | `interaction_type`: one of 8 generic types, described in `meta.interaction_types` |

**Interaction types:**
- **Reuse the breath orb for `breath_pacer`:** it needs its timings configurable from `pacer` (`inhale_s`, `second_inhale_s`, `hold_s`, `exhale_s`).
- **Possibly new components:** `guided_steps`, `text_prompt`, `checklist`, `drawing_canvas` (with `canvas_template`: `mandala` or `blank`), `audio_player`, `timer` and `offscreen_card`. Check what exists before building anything.
- **`offscreen_card`** means "go and do this away from the screen", with a timer and a done button. It's the cheapest way to add the walk, nap, nature and kindness activities.

## Integration steps

1. **Pick the defaults.** For each class, start with the `default_three` activities. They replace or join the current three; the MVP's limit of three still works.
2. **Use one source of truth.** Generate both gate.py `ACTIVITIES` and frontend `activities.ts` from `mvp_activity_pack.json`, rather than copying by hand. This also fixes the drift between the two tables.
3. **Durations.** If the UI must stay at 60–90 s, use `short_version_seconds`, and skip activities where it is `null` (off-screen activities). Show the "Want the full version?" option with `duration_seconds`. `evidence.dose_gap_note` explains the gap.
4. **Citations.** Add a "Why this?" link that shows `evidence.citations[0].citation_short` and opens `url`.
   - Store the full `citations` array with the activity so saved sessions can show it.
   - Show a citation without caveat only if its `verification_status` is `verified_fulltext`, `verified_abstract` or `corrected`.
   - For other statuses, either don't show the effect size, or label it "not independently checked".
5. **Safety.** Keep skipping activities for crisis and blocked results. Never surface any id in `never_suggest_activity_ids`. `contraindicated_classes` is empty for every row in this pack; keep the check if you add activities later.
6. **Positive classes.** `calm_flow` and `radiant_joy` activities are for savouring or sharing a good state. Present them as optional ("If you like…"), not as fixes.

## Optional improvements the data supports

These need no new research, just code:

- **Rotation:** rotate through the rest of the class list on repeat sessions, so people don't always see the same three.
- **Runner-up blending:** if the second-highest score is close to the top one, swap the third default for the runner-up class's top activity. Each activity's `also_supports_classes` lists other classes where it also has evidence. For example, `slow_breathing` supports stress, anxiety, mental fatigue and calm flow, so it is a safe pick when stress and anxiety are close.
- **Personalisation:** filter or reorder by `preference_tags` (creative, physical, social, solo, indoor, outdoor, mindful, cognitive, musical, verbal, hands-on, low-effort, high-energy) and `requirements` (e.g. "outdoors", "somewhere to lie down").

## Notes on the existing MVP activities

These are in `existing_mvp_activity_notes`:

- **4-7-8 breath orb:** no evidence for the 4-7-8 pattern itself was found. The evidence is for slow breathing at about 6 breaths a minute and for cyclic sighing, without long holds. Add a no-hold preset (in 4 s, out 6 s), or label 4-7-8 as a variation without its own evidence.
- **Pendulum pacer:** not covered by the research. Don't attach a citation to it.

## Field reference

| Field | Meaning |
|---|---|
| `evidence.grade` | A = at least one meta-analysis, systematic review or RCT confirmed against PubMed; B = other confirmed evidence, or an unconfirmed meta-analysis/RCT; C = preliminary, unconfirmed or indirect only |
| `evidence.basis` | `direct`: the study measured this class's emotion (stress, anxiety, fatigue, calm or positive affect). Every row in this pack is direct |
| `evidence.dataset_evidence_score` | The research dataset's 0–1 ranking score for this activity and emotion (uncalibrated weights; for ordering only) |
| `citations[].verification_status` | How far the citation was checked: `verified_fulltext`, `verified_abstract`, `corrected` (checked and fixed), `citation_exists_number_not_confirmed`, `not_in_pubmed` (could not be checked) |
| `citations[].effect_size` | As reported, with checking tags such as [P] (PubMed abstract) or [A] (search abstract only). Not standardised across studies |
| `citations[].single_session_evidence` | Whether the study tested a single session (`true`) or a multi-week programme (`false`) |
| `cautions` | Short cautions from the research; show the relevant one for physical activities and naps |

## Caveats to keep in the product

- The sketch scores are not a validated measure of emotion; let people skip or change the suggestions.
- Most tested doses are 5–30 minutes. A 60–90 s version is a taster, not the studied intervention.
- These are general wellbeing suggestions, not treatment.
